# Code

Follow the README in each figure directory to run its plotting scripts. The workflow uses the supplied aggregate tables to reproduce the public versions of analytic results and Figs. 1-5. Expected runtime is a few minutes on a standard desktop.

The plots for [Fig. 1](Fig1_gender_PA_disparities/figures/) and [Fig. 2](Fig2_nighttime_gender_gap/figures/) are in each module's `figures/` directory. Figure 1 also includes [maps](Fig1_gender_PA_disparities/maps/). [Fig. 3](Fig3_nonlinear_curve_onset/output/), [Fig. 4](Fig4_forestplot_sensitive_plot/output/) and [Fig. 5](Fig5_longitudinal_comparison/output/) each provide PNG, SVG and PDF files in `output/`.
