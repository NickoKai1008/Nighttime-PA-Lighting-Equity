# Code availability

The analysis scripts are provided in `code.rar`; `code/00_data_preparation` through `code/07_supplementary` document the data preparation, descriptive analysis,
multilevel modelling, GAMM response estimation, response-range extraction, policy simulation and validation workflow. 
These scripts require authorized local access to the restricted Strava and SDGSAT-1 inputs.

The scripts in `Figure_code/` reproduce the public analytic results and figures from the provided synthetic and aggregate tables.
